# PRD — Aplicativo de Finanças Pessoais com IA

## 1. Visão do Produto

Criar um aplicativo moderno de organização financeira pessoal que permita ao usuário controlar receitas, despesas, metas e hábitos financeiros usando uma experiência simples, visual e conversacional com Inteligência Artificial.

O diferencial do produto é reduzir o esforço manual. Em vez de exigir que o usuário navegue por várias telas, ele poderá registrar gastos, fazer perguntas e receber análises por meio de linguagem natural.

## 2. Objetivo

Ajudar jovens adultos, universitários, trabalhadores CLT e pequenos empreendedores a entenderem para onde o dinheiro está indo, controlarem seus gastos e tomarem melhores decisões financeiras.

## 3. Problema

Aplicativos financeiros tradicionais costumam ser complexos, exigem muitos lançamentos manuais e não explicam os dados de forma simples. Isso faz com que muitos usuários abandonem o controle financeiro após poucos dias.

## 4. Solução

Um aplicativo financeiro com IA que:

* Registra receitas e despesas.
* Categoriza automaticamente os gastos.
* Gera gráficos simples.
* Acompanha metas financeiras.
* Identifica desperdícios.
* Faz previsões de gastos.
* Envia dicas inteligentes.
* Responde perguntas em linguagem natural.

## 5. Público-alvo

### Jovens adultos

Querem controlar gastos do dia a dia, cartões, delivery, lazer e assinaturas.

### Universitários

Precisam administrar orçamento limitado, bolsa, estágio ou ajuda familiar.

### Trabalhadores CLT

Querem controlar salário, contas fixas, cartão, reserva de emergência e metas.

### Pequenos empreendedores

Precisam separar vida pessoal e pequenos fluxos financeiros do negócio.

## 6. Proposta de Valor

## 13. Modelo de Categorização Automática

### Primeira versão

Usar regras simples:

* “iFood”, “restaurante”, “mercado” → Alimentação.
* “Uber”, “99”, “metrô”, “ônibus” → Transporte.
* “Netflix”, “Spotify”, “Prime” → Assinaturas.
* “farmácia”, “consulta”, “exame” → Saúde.

### Segunda versão

Usar IA para classificar descrição, valor e histórico do usuário.

Exemplo de prompt interno:

“Classifique esta despesa em uma das categorias disponíveis do usuário. Responda apenas com o ID da categoria mais provável.”

## 14. Chat IA

### Como deve funcionar

1. Usuário faz uma pergunta.
2. Backend busca dados financeiros relevantes.
3. Backend envia contexto resumido para a IA.
4. IA responde com linguagem simples.
5. App exibe resposta e possíveis ações.

### Exemplo

Pergunta:

“Posso comprar um celular de R$3500?”

Dados enviados para IA:

* Saldo atual.
* Receitas do mês.
* Despesas do mês.
* Metas ativas.
* Média de economia.
* Gastos previstos.

Resposta esperada:

“Você até pode comprar, mas isso consumiria 70% do seu saldo atual e atrasaria sua meta de viagem em cerca de 2 meses. Uma alternativa mais segura seria parcelar até R$600 por mês ou esperar mais 3 meses.”

## 16. Requisitos Não Funcionais

### Segurança

* Autenticação obrigatória.
* Dados isolados por usuário.
* Row Level Security no Supabase.
* Não expor chave da OpenAI no frontend.

### Performance

* Dashboard deve carregar rapidamente.
* Consultas financeiras devem ser otimizadas por usuário e data.

### Usabilidade

* Interface simples.
* Poucos campos por tela.
* Ações rápidas.
* Linguagem amigável.

### Escalabilidade

* Separar frontend, backend e banco.
* Criar serviços independentes para IA, transações e relatórios.

### Privacidade

* Dados financeiros são sensíveis.
* O usuário deve poder excluir sua conta e seus dados.
* Evitar enviar dados desnecessários para a IA.

## 20. Riscos

### Baixa adesão por cadastro manual

Mitigação: permitir entrada via chat e importação de extrato nas próximas versões.

### Custo alto da IA

Mitigação: usar resumos financeiros, cache de insights e limitar contexto enviado.

### Respostas financeiras ruins

Mitigação: deixar claro que a IA oferece orientação, não consultoria financeira profissional.

### Dados sensíveis

Mitigação: segurança forte, RLS, criptografia e política clara de privacidade.

## 25. Conclusão

O produto deve começar simples: registrar transações, mostrar dashboard e permitir perguntas para a IA. O grande diferencial não está apenas em ter gráficos, mas em transformar dados financeiros em respostas claras, úteis e acionáveis.

O MVP ideal deve validar três coisas:

1. O usuário consegue registrar receitas e despesas facilmente.
2. O dashboard ajuda o usuário a entender sua situação.
3. O chat IA gera valor real e reduz a complexidade do controle financeiro.
